# Ablauf bei einer Datenpanne (Art. 33/34 DSGVO)

1. **Sofort eindämmen:** betroffene Funktion abschalten (z. B. D1-Bindung im Pages-Projekt entfernen → API antwortet 503), Zugangsdaten zum Cloudflare-Konto ändern.
2. **Bewerten:** Welche Daten, wie viele Konten, welches Risiko? (Bei Rookie: keine Kontaktdaten, keine Passwörter – Risiko meist gering.)
3. **Melden innerhalb von 72 Stunden** an die Datenschutzbehörde (https://www.dsb.gv.at → Formular „Data Breach“), außer es besteht voraussichtlich kein Risiko für die Betroffenen. Begründung dokumentieren.
4. **Betroffene informieren**, wenn ein hohes Risiko besteht – z. B. per Hinweis in der App (es gibt keine E-Mail-Adressen).
5. **Dokumentieren** (Art. 33 Abs. 5): Was ist passiert, Auswirkungen, Maßnahmen – auch wenn nicht gemeldet wurde.
